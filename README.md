# Cơm Nhà Customer Information & Relationship Tool
## ICT303 Week 10 Prototype

This is a browser-based front-end prototype created for the ICT303 Group 8 project.

### Purpose
The prototype demonstrates a simple staff-facing customer information tool for Cơm Nhà Restaurant.

### Demonstrated functions
- Search for a customer by name, phone or email
- Identify customers as new or returning
- View customer contact details
- View visit/reservation history
- View customer preferences
- View staff notes
- Add a new customer
- Add a customer note
- Basic authorised staff access concept

### How to run
1. Download/extract the prototype folder.
2. Open `index.html` in a web browser.
3. No installation or server is required.

### Technical approach
- HTML
- CSS
- Vanilla JavaScript
- Browser localStorage for prototype-only persistence
- Sample data used for demonstration

### Important scope note
This is a prototype only. It is not a production CRM, POS replacement, payment system or live customer database.
